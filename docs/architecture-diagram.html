传输与会话

并发串扰防护（M3+）

exec-guard.ts — 防漏网：命令随机 token 标记包裹，响应缺标记即判串扰抛错 → 3 次重试换标记重发

slurm.ts — sinfo/sbatch/scancel 命令构造与解析

3
pre → run → sbatch
秒级返回 slurm job id + 后台作业 id；producer（kind slurm）接管监控
→
4
自适应轮询
服务端按 10/60/120/300s 档批量 sacct，经 exec-gate/guard 过闸，零模型请求
→
5
COMPLETED → 自动 post
解析物性：energy / converged / frequencies / 虚频数 + files；写入 sqlite 结果记忆
→
6
结算回投
job_output 逐作业终态表 + 宿主完成通知 + 状态板 / 状态卡片；结构化结果按同步策略落本地
非 COMPLETED：跳过 post，带 log_tail 诊断返回
post 失败 ≠ 作业失败：物性解析失败不判计算链失败
job_kill 只取消本地监控，不动集群作业
job_watch 并行通道：多作业批量注册，全终态/超时/连续 5 次传输异常/取消 四路结算
