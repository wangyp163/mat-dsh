# P2 Compaction 调优实验 + 取证（2026-10-15）

> 性质：harness engineering 路线 P2 完整实施态。前置：P0.5 评测基线、P1 沙箱。
> 结论先行：**摘要压缩在健康窗口下是"溢出保险"而非日常主力——激进触发
> 在本尺度上是净亏损（token +1.5~2.5×、墙钟 ×2~5、还有压缩风暴超时风险）；
> 确定性剪枝（pruner）才是免费的日常杠杆。**

## 0. 判定修正与机制发现（六轮冒烟定位，全部可复现）

P0 判定"有但未调优未取证"→ 实施中发现四个**文档未显式记载的联动机制**：

1. **pi-ai 输出预算算术**：`min(显式 maxTokens ?? 模型能力, 声明窗口 −
   prompt 字符估算 − 4096)`。声明窗口过小 → 输出被挤到个位（实测 out=2 的
   max-tokens 死）。实验泳道必须同时声明窗口与模型级 maxTokens。
2. **阈值可达性**：估算器计价偏保守 + 4096 安全垫，thresholdRatio 0.8 与
   "输出不饿死的最小窗口"联立后摘要压缩**几乎不可达**（40960 是本任务形态
   的健康下界；DEFAULT 泳道 16 步的 composite 也只触发 1 次）。
3. **retainRatio < thresholdRatio 硬校验**：压缩后必须落到阈值之下，否则
   永久重触发（config 校验器强制，smoke7 实锤报错）。
4. **填充的反直觉**：结果超过 pruner 阈值（8192 字符）后可见部分被钉死在
   ~5k 字符；**恰好低于阈值的中等结果才是最大上下文累积向量**（攻击面
   认知：想撑爆上下文要用"多条中等"而非"一条巨大"）。

**失败谱系**（区分机制归因）：
- 退出码断言未命中 ×4（含 NOPRESSURE）——**模型方差的指令遵循问题**，与
  压缩无关（对照泳道同样丢）；
- EARLY r2 双任务超时（480s 上限）——**压缩风暴的墙钟代价**：9 次摘要 =
  9 次额外 reasoning-high LLM 调用；
- GOLDEN-7F3K 丢失 ×1——与 7 次压缩 + 超时耦合（任务提示含代号的首批
  surface 被 seq 7-9 遮蔽），归因存疑但方向警示：**摘要不保证保留"弱显著
  性"信息（会话代号类）**。

## 2. 三问回答

### Q1 token 省多少？
**本尺度上是净支出而非节省**。未命中缓存口径的输入 token：NOPRESSURE
21-27k/任务 → EARLY 34-61k（+50~130%）。两个成本源：(a) 每次摘要是一次
全价 LLM 调用（前缀=system+全部历史）；(b) **压缩后稳定前缀失效**，后续
请求全量重读（步级轨迹：稳态 ~0.3-1k 未命中 → 压缩后单次 4-12.7k）。
收益侧（避免历史无限增长）在本尺度不可见——回放泳道够不到那个量级。
**微观结论：pruner 是免费杠杆（确定性、零 LLM），能压住的别留给摘要。**

### Q2 成功率与信息存活是否受损？
方差不归压缩：同配置两轮 EARLY 一轮 2/2 一轮 0/2；对照泳道也丢断言。
真正的压缩特有风险两条：墙钟风暴（→超时）与弱显著性信息不保证存活。
retainRatio 0.12 的 FAT 泳道信息存活完好（能量/收敛/虚频全数出现在最终
答复）——**厚尾巴有效**。

### Q3 KV-cache 稳定前缀被打断的代价怎么讲？
量化口径就用"未命中缓存输入 token"：稳态下每请求仅 ~0.3-1k 未命中（前缀
全缓存），每次压缩后的第一个请求跳到 4-12.7k（全量重读）+ 摘要调用自身
的整段前缀账单。**叙事：compaction 是"一次全价重读换后续每步瘦身"的交易
——短会话净亏，长会话是必要恶；调优目标是最大化确定性剪枝的占比，把摘要
压缩留作溢出保险（宿主默认 0.8 阈值正是这个哲学）。**

## 3. 生产建议（对 mat 会话）

1. 维持 compaction-basic 默认（0.8/0.16）——本项目会话（多波批任务）长度
   下 pruner+溢出保险的组合已足够；DEFAULT 泳道 2/2 全过即证据。
2. 若未来出现真长会话（日级 shepherd 续跑）：优先调 retainRatio（保信息）
   而非降 thresholdRatio（引风暴）；摘要模型可显式指到 flash 档省钱。
3. 断言工程教训（第 4 次）：跨泳道稳定复现的失败才归因 harness；单轮失败
   先怀疑模型方差——**这就是关键结论跑 2 轮的原因**。
