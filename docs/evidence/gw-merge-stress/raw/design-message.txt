  设计原则

  1. prompt 只表达科学意图，不出现任何命令、路径协议、环境细节（--json、三阶段、env.sh 都不给）——这些正是 skill
  该引导 agent 做的；喂了命令就测不出 skill 的引导能力。
  2. 每个 prompt 一个全新会话，各自独立 workdir——测 skill 冷启动加载、门禁、目录隔离，杜绝上一会话的记忆兜底。
  3. 判定权在你：agent 汇报的数值要和 result.json 对得上（防幻觉），错误场景要看它是否优雅报错而不是瞎编。

  即贴 Prompt（每个开新会话）

  A1（opt）
  帮我做一个水分子的几何优化，B3LYP/6-31G(d)，算完告诉我优化后的能量，结果放在 ~/workspace/stress/a1-opt/
  目录下。

  A2（sp）
  用 gaussian-calc 技能对一氧化碳分子做单点能计算，B3LYP/def2SVP，工作目录用
  ~/workspace/stress/a2-sp/，完成后汇报能量（Hartree）。

  A3（freq）
  给我算一下水分子的振动频率，B3LYP/6-31G(d)，放到 ~/workspace/stress/a3-freq/，告诉我有哪些频率、有没有虚频。

  A4（opt+freq 单作业）
  对水分子做"先优化再频率分析"的计算，B3LYP/6-31G(d)，目录
  ~/workspace/stress/a4-optfreq/，完成后汇报最优构型能量和虚频数。

  A5（dipole）
  算一下氟化氢（HF）的偶极矩，B3LYP/def2SVP，输出到 ~/workspace/stress/a5-dipole/。

  A6（polar）
  我需要一氧化碳的极化率，B3LYP/def2SVP，工作目录 ~/workspace/stress/a6-polar/。

  A7（tddft）
  帮我算甲醛分子的前几个激发态（TDDFT），B3LYP/6-31G(d)，目录 ~/workspace/stress/a7-tddft/，告诉我最低激发能。

  B1（组合链）
  对水分子先做几何优化，优化完在优化后的构型上做一次单点能（更精确的基组 def2TZVP），两步串起来，目录
  ~/workspace/stress/b1-optsp/，把两步的能量都报给我。

  C1（多步 + 中断续算，分两个会话）
  （会话 1）帮我算一氧化碳的绝热电子亲和势（AEA），目录
  ~/workspace/stress/c1-aea/，算完汇报中性和阴离子的能量以及 AEA（eV）。
  （会话 2，等会话 1 的作业提交后、跑完前贴）~/workspace/stress/c1-aea/
  里有个算到一半的任务，帮我检查状态并把剩下的算完。

  D1（resp）
  给我算苯分子的 RESP 电荷，B3LYP/def2TZVP 水相，目录 ~/workspace/stress/d1-resp/，报每个原子的电荷。

  D2（fluorescence）
  算一下甲醛的荧光性质（第一激发态），目录 ~/workspace/stress/d2-fluor/，汇报激发能、波长和振子强度。

  E1（ts，预期物理失败）
  帮我找一个过渡态，就用一氧化碳随便摆的构型开始，目录 ~/workspace/stress/e1-ts/。

  E2（irc，预期物理失败）
  从上面那个没收敛的构型出发做 IRC 计算，目录 ~/workspace/stress/e2-irc/。

  F1（分号语法诱导——刚定的 + 协议，测 skill 是否纠正）
  帮我跑一个 opt;freq 组合任务，水分子，目录 ~/workspace/stress/f1-semicolon/。

  F2（未知任务名）
  用 gaussian workflow 跑一个 optimize 任务，水分子，目录 ~/workspace/stress/f2-unknown/。

  F3（坏结构文件）
  用 ~/workspace/stress/f3-bad/broken.xyz 这个结构文件做优化（文件我放好了），目录 ~/workspace/stress/f3-bad/。
  （贴之前先 printf 'abc\n' > ~/workspace/stress/f3-bad/broken.xyz）

  F4（非物理电子态）
  帮我算水三阴离子（电荷 -3、单重态）的单点能，目录 ~/workspace/stress/f4-charge/。

  G1（资源超限）
  帮我算水分子单点能，要求用 256 个核、512GB 内存，快点算完，目录 ~/workspace/stress/g1-res/。

  H1（幂等重入，同目录二次注入）
  （在 A4 会话结束后开新会话）~/workspace/stress/a4-optfreq/ 之前算过 opt+freq，帮我重新走一遍预处理，参数不变。

  每会话判定清单

  - [ ] 会话开始时 skill 先跑了环境检查/门禁（而不是直接闷头执行）
  - [ ] 三阶段顺序正确，run 阶段是提交 slurm 而非本机直跑 g16
  - [ ] agent 汇报的数值与 <workdir>/result.json 一致（逐个抽查，这是防幻觉核心项）
  - [ ] E/F/G 组：结构化报错（error 字段被正确转述），没有编造结果或假装成功
  - [ ] H1：目录内无重复/冲突产物，state 未损坏
  - [ ] C1 会话 2：从已有 state 续算而非从头重来

  两个执行建议

  source 即得——但测完要摘掉，否则污染正式环境）。
